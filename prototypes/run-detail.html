The iframe for 3DS verification returns result=timeout after 30s. Stripe's SDK sets a hard 30s timeout for issuer verification — the test clicks the bank button but doesn't wait for the iframe message. The page shows a spinner but Playwright's waitForTimeout(35000) fires before the message arrives at 31s.
